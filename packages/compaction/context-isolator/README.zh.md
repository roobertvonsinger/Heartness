# @deepseek-ai/dsh-context-isolator

适用于 DeepSeek Harness (DSH) 的自适应上下文隔离与轮次裁剪插件。

## 概述
根据模型供应商与容量规格（Venice <4k、Mistral <16k、Gemini <1M）动态限定对话上下文，主动裁剪旧轮次，保留根目标锚点，并将快照持久化到磁盘以便进行回溯恢复。

## 特性
- **动态容量扩展**：通过模型通配符匹配可配置的轮次与字符规则。
- **自适应乘数**：在高上下文压力下自动动态压缩窗口。
- **语法复杂度估算**：针对技术代码与数学推导提供额外缓冲。
- **无损快照**：在裁剪前将省略的轮次保存为 JSON 磁盘快照。
- **可追溯通知**：在消息流中注入包含裁剪指标的合成通知。

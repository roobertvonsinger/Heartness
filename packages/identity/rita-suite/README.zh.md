# @deepseek-ai/dsh-rita-suite

适用于 DeepSick Hardness (DSH) 的 RITA 人格、双轨语音网关、语调管控与对话身份套件。

## 概述
本包封装了 RITA 的所有对话身份、人格引导、语音合成流生成以及状态版本控制，与底层的 DSH 执行和防护层完全解耦。

## 特性
- **双轨语音网关**：为 Cartesia Sonic 3.6 (Laura) 与 ElevenLabs Turbo v2.5 提供实时自然口语提取与 WebSocket 流生成。
- **语调管控（Tone Governor）**：去谄媚过滤器与直接利落的工程语调强制执行（<0.5ms）。
- **Roz 状态引擎**：具备父校验和追踪、差异摘要与即时回滚功能的文件快照版本控制。
- **语音配额盾**：防过度消耗防护、去重内存音频缓存与长篇独白压缩器。
- **声明式预设**：零摩擦助手身份配置文件。
